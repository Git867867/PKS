# Walkthrough — бронирование авиабилетов

КР №1 остается в проекте: модели, JDBC, сервисы, консольное меню, `init.sql`.
КР №2 добавляет настольное окно JavaFX к той же базе `airline_booking`.

## Как устроен запуск окна

```text
AirlineFxApp
  читает database.properties через DatabaseManager
  создает PassengerRepository и BookingRepository
  создает PassengerService и BookingService
  загружает fxml/main-view.fxml
  отдает сервисы в MainController
```

Дальше кнопка не пишет SQL. Цепочка всегда одна:

```text
FXML-кнопка → метод контроллера → метод сервиса → метод репозитория → PostgreSQL
```

## Что показывает окно

Вкладка «Бронирования»:

- таблица рейсов;
- поиск по номеру рейса, имени пассажира и городам;
- фильтр по статусу;
- фильтр по городу;
- сортировка по дате вылета и по цене;
- добавление, изменение, удаление с подтверждением;
- обновление из базы;
- статистика;
- экспорт текущего списка в Excel (.xlsx) и в CSV через выбор файла;
- внизу — данные выбранного пассажира.

Вкладка «Пассажиры»:

- список пассажиров;
- добавление, изменение, удаление;
- внизу — рейсы выбранного пассажира.

Пассажира в форме бронирования выбирают из списка, а не вводят его номер вручную.

## Сценарий демонстрации

1. Убедиться, что PostgreSQL запущен и база `airline_booking` заполнена скриптом `init.sql`.
2. Запустить `mvn javafx:run`.
3. Показать таблицу: рейс, пассажир, города, дата, цена, статус. Технический `passenger_id` в таблице не показывается.
4. Выбрать строку. Внизу появляются email, телефон и паспорт пассажира.
5. Найти `SU` или `Петров`. Список сужается.
6. Поставить статус «Создано» и город «Москва».
7. Переключить сортировку «по цене (сначала дешевле)». Показать, что заголовок столбца тоже сортирует таблицу.
8. Нажать «Сбросить», затем «Обновить».
9. «Добавить»: выбрать пассажира из списка, рейс `SU-777`, Москва — Казань, дата в ближайший месяц, время `10:00`, цена `4500`. Статус нового бронирования всегда «Создано».
10. Показать ошибку: пустой рейс, цена `0`, одинаковые города или дата в прошлом. Текст говорит, что исправить.
11. «Изменить» у только что созданной записи: поменять цену и статус на «Подтверждено». Переход «Завершено» из «Создано» в списке статуса нет: такое правило уже было в КР №1.
12. «Удалить» и отказаться в окне подтверждения. Затем удалить и согласиться.
13. Вкладка «Пассажиры»: выбрать человека и показать его рейсы. Удаление пассажира каскадное: подтверждение говорит, сколько бронирований удалится вместе с ним.
14. «Статистика»: шесть показателей по всей базе.
15. «Экспорт Excel»: выбрать папку в диалоге и открыть `.xlsx`. «Экспорт CSV» сохраняет тот же список текстовым файлом.

## Покрытие требований КР №2

| Требование | Где |
|---|---|
| Окно с основными действиями | `main-view.fxml`, `MainController` |
| TableView и ObservableList | таблица бронирований |
| Добавление, правка, просмотр | `booking-form.fxml` |
| Удаление с подтверждением | `FxDialogs.confirmDelete` |
| Связанный пассажир выбирается из списка | `ComboBox` в форме бронирования |
| Просмотр связанных данных | нижние панели обеих вкладок |
| Поиск по нескольким полям | рейс, пассажир, город вылета, город прилета |
| Два фильтра | статус и город |
| Две сортировки | дата и цена, плюс сортировка заголовком столбца |
| Проверка ввода | сервисы и форма |
| Понятные ошибки | диалог и красная подпись на форме |
| FXML | четыре файла в `src/main/resources/fxml` |
| CSS | `src/main/resources/css/app.css` |
| Слои | Controller, Service, Repository |
| Минимум 5 показателей | окно статистики, их 6 |
| Экспорт | Excel и CSV через `FileChooser` |
| Пароль не в исходном коде | `database.properties` |
| SQL не в кнопке | SQL остается в репозиториях |

## Запуск

```powershell
mvn javafx:run
```

Консоль КР №1:

```powershell
mvn package
java -jar target/airline-booking-1.0-SNAPSHOT.jar
```

Подключение к базе задается в `src/main/resources/database.properties`.
